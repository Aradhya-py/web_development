Mathematics Formula Sheet

Algebra

Square of a Sum:
(a + b)2 = a2 + 2ab + b2

Square of a Difference:
(a - b)2 = a2 - 2ab + b2

Sum of Squares Deduction:
a2 + b2 = (a + b)2 - 2ab

Quadratic Formula Discriminant and Roots:
x1,2 = (-b ± √(b2 - 4ac)) / 2a

Geometry

Distance Formula between two coordinate points P1(x1, y1) and P2(x2, y2):
d = √((x2 - x1)2 + (y2 - y1)2)

Pythagorean Theorem for a right-angled triangle:
a2 + b2 = c2
